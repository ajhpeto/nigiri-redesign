# Nigiri.Finance TypeScript concept

A responsive React + TypeScript implementation of the approved clean Nigiri homepage direction, including light/dark themes and local image assets.

## Run locally

```bash
pnpm install
pnpm dev
```

For npm users:

```bash
npm install
npm run dev
```

## Production build

```bash
pnpm build
```

Read `COPILOT-BRIEF.md` before continuing the design with GitHub Copilot.

Opportunity data and legal links in this concept are illustrative and require approval before production use. Generated visual assets should also be reviewed and replaced with licensed project photography where appropriate.
